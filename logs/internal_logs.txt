Zen v3.0.0 — Internal Changelog
===============================

Reference for updating the docs. Grouped by area.


BREAKING CHANGES
----------------

- `toString` / `toInt` renamed to `intToAscii` / `asciiToInt` (ASCII conversion).
- `private` is now a reserved keyword (functions, methods, fields). Any identifier named `private` collides.
- Keyword `in` removed.
- Classic loop must always be `loop (init, cond, update)`.
- `+` with any string operand converts the other operand to string and concatenates.
- `fs.writeFileBytes` now returns `int` (success code) instead of `void`.
- `sqrt` now takes `double` and returns `double` (was `int`).
- `zen tests` renamed to `zen test`.
- `zen -v` changed to `zen --v`.
- Windows support temporarily paused in this version.


LANGUAGE AND TYPE SYSTEM
------------------------

- Numeric widening formalized: `byte -> int -> long -> double`.
- `bool` works in arithmetic (`true`=1, `false`=0) and bitwise ops.
- New bitwise operators: `&  |  >>  <<  ~`. Unary `+` added.
- `infer` supports: `int`, `bool`, `double`, `string`, `long`, `byte`. Errors on list/struct/other.
- Compile-time constants: `int N = 10; int arr[N]`.
- `sizeOf()` supports bare types and expressions. Bare struct names are unsupported (instantiate first).
- Struct field initializers with defaults. Uninitialized structs get zero-value fields (`0`, `""`, `false`, empty list). Struct literals only set the fields given.
- Anonymous inline functions as callback args: compiled as separate functions, no closures (cannot capture outer variables).
- Named functions passed as callbacks can use closure (outer variables allowed).
- Multiple exports/imports per file. Import aliasing works for functions and variables only (not structs).
- Thread fns accept parameters and report capture errors at compile time.
- Thread methods in structs spawn correctly.
- Chained calls on returned structs work: `make().show()`.


LITERALS AND ESCAPES
--------------------

- `byte` is signed: -128 to 127. With a byte suffix, out-of-range values wrap (two's complement).
- Scientific notation for doubles: `1e300`, `1.5e-10`, `2E+5`. Supported in source parsing and in LLVM double formatting (fixes invalid constants like `1e-9` with no decimal point).
- Hex literals with no suffix are always `int`: `0xFB` is int 251, not a byte.
- Hex with a type suffix needs an underscore: `0xFB_B` is byte, `0xFF_L` is long.
- Decimal suffixes unchanged: `20B`, `42L`.
- New string escapes `\e` and `\xHH` (`readEscape()` in lexer, ESC handling in `toLLVMString`). Example: `"\e[31m"` for ANSI colors.


STDLIB AND RUNTIME
------------------

Globals
- `lastIndexOf` added.
- `stringToBytes` / `bytesToString` added.
- `length()` accepts a List directly, alongside `list.length`.
- Naming: `extName()` returns no dot, `path.extname()` returns with dot.

List methods: `remove()`, `reverse()`, `sort()`, `sum()`, `avg()`, `flat()` (any depth to depth 1).

Map methods: `keys()`, `entries()`.

Json.map()
- Builds a Map from JSON.
- JSON numbers (JS number type) can be read with `getInt()`, `getByte()` or `getLong()`.
- Overflow is checked at runtime per getter (int overflow, byte overflow, etc.).

Namespaces
- `fs`: `listDir`, `isFile`, `isDir`.
- `sys`: `spawn`, `kill`, `isRunning`, `wait`.
- `threads`: `count()`, `currentId()`.
- `HttpRequest.getHeader` added.

TCP (native: `tcp.c`)
- Structs: `Tcp`, `TcpServer`.
- `net.online()`, `net.connect(host, port)`, `net.listen(port)`.
- `Tcp`: `send()`, `receive()`, `close()`, `isOpen()`.
- `TcpServer`: `accept()`, `close()`, `isOpen()`.

New constants: `SQRT1_2`, `SQRT3`, `LOG2E`, `LOG10E` (double); `BYTE_MAX`, `BYTE_MIN` (i8); `I64_MAX`, `I64_MIN` (i64).


HTTP
----

- `http.getProgress(string url, fn cb(long downloaded, long total) void callback) -> List<byte>`: downloads a URL and reports downloaded and total bytes through the callback. Returns the data as `List<byte>` for low-level control.
- Connect timeout: 10 s for every request. Fails if the server can't be reached.
- Without a progress callback (get/post/put/patch/delete): hard total cap of 30 s.
- With a progress callback (`getProgress`): no total cap. Aborts only if speed stays below 1 KB/s for 30 s (`CURLOPT_LOW_SPEED_LIMIT` / `LOW_SPEED_TIME`).
- On any curl error (including timeout or "Operation too slow"), `http_error()` prints a NetworkError and exits.
- Tested: 3.4 MB PDF (`gcc.pdf`) downloads correctly.


PACKAGES AND CLI
----------------

- `zen install` / `zen uninstall` accept multiple package names.
- `zen installed`: lists installed package count.
- `zen deps` auto-detects/records `native/*.o`. Native objects auto-link. `.c` files supported as native deps.
- `zen.json` `flags: []` at module + standalone level (e.g. `--flags -lmariadb`).
- `--link a.o b.o` supported.
- `zen read pkgName [--raw]`: renders package README in terminal.
- `zen update --dev`: installs dev version.
- `zen upgrade pkgName`; `zen install pkg@semver`.
- `zen test pkg-name`: runs the package's `test.zen`.
- `zen --v` shows version; `zen --v pkgName` / `zen --version pkgName` shows an installed package's version.
- `zen info` (namespace/global, with `--methodName`).
- Interactive REPL (`zen` with no args), prints "Bye!" on `exit()`.
- `zen version pkgName`: shows the installed version of a package (separate command from `zen --v`).

TOOLING
-------

- LSP server enhanced: `zen lsp` (used by editors).
- Formatter enhanced, bugs fixed.
- Linter fixed.
- Better compile-time diagnostics: hints + source text.


INSTALLER (`INSTALL.SH`)
------------------------

- `--tag` / `--branch` install modes. Branch installs skip the VERSION check and version off the short commit hash.
- Verified end-to-end on Termux (Android). Reviewed for apt/pacman/dnf/zypper Linux paths.
- Windows unsupported for now (documented, not auto-installed).


COMPILER INTERNALS
------------------

- Thread methods spawn via `_zen_thread` (method call path in `expression.js`).
- Thread ctx freed in trampoline; string args duplicated and freed per thread.
- Structs record transitive deps (fields, `List<T>`, method params/returns).
- Importing a struct or fn implicitly registers its deps as hidden structs: usable through the export, not nameable. Clear errors on naming or clash. Hidden struct is promoted when explicitly imported. Emitted types/methods deduped.
- Unknown-struct error unified in member chain walk.
- Parser allows chained access after a statement-level call; `call.js` emits the method-call expression when used as a statement.
- `setStruct` takes the node, so redefinition errors show line info.
- Architecture documentation added.


KNOWN LIMITATIONS
-----------------

- Structs cannot be imported with an alias (ImportError).
- `debug.pretty()` does not support user struct fields of type `List<Map>`.
- `sizeOf()` does not accept bare struct names.
- HTTP: no user-configurable timeouts, no retry/resume.
- Windows support paused.
